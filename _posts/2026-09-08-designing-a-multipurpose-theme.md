A multipurpose theme should not make a portfolio, documentation site, and magazine look like variations of the same blog index.

## Start with information architecture

Each site type answers a different visitor question. A portfolio asks “what have you made?” Documentation asks “how do I use this?” A landing page asks “why should I care?”

Jekyll collections and front matter let each answer keep the structure it needs while sharing a visual system.
