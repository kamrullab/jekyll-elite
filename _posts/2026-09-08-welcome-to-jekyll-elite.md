This starter now includes the essentials for a small Jekyll site: reusable layouts, a responsive design, and support for Markdown posts.

## Built for clear content

The theme uses semantic Liquid templates and a compact design system. Site owners can replace any layout or include while continuing to use the remaining theme files.

## Ready to customize

Edit site metadata and behavior in `_config.yml`, navigation in `_data/navigation.yml`, and visual tokens at the top of `_sass/jekyll-elite.scss`.
